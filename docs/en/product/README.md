# Product Specifications (`docs/en/product/`)

## What is this directory?
Centralizes strategic product vision, problems solved, supported user personas, and explicit scope boundaries.

## Purpose
Prevents engineering waste by ensuring developers and autonomous agents understand the *why* behind every capability before implementation begins.

## Inventory
- `vision.md`: Product vision, value proposition, and user personas.
- `scope.md`: Explicit in-scope and out-of-scope boundaries for the current product iteration.
