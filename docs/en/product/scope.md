# Product Scope

## In-Scope
- Modular, contained terminal editing capabilities and robust rope data structures.
- Complete automated test suite covering units, integration, and UI regressions.
- Automated security validation (SAST, secret scanning, dependency auditing).
- Living canonical documentation with structured `README.md` files across all workspaces.

## Out-of-Scope
- Generic abstractions without concrete use cases.
- Unconstrained feature additions outside of approved roadmaps.
- Undocumented contract modifications or architectural boundary leaks.
