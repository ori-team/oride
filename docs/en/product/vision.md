# Product Vision

## Value Proposition
Deliver a highly dependable, modular, and self-documented terminal IDE and code editor, engineered for fluid, high-velocity collaboration between human developers and autonomous AI agents.

## Personas
- **Software Engineer**: Demands a fast, modular, lean code editor with deterministic tests and living documentation.
- **Technical Lead**: Requires architectural integrity, rigorous security baselines, and traceable decision records.
- **AI Coding Agent**: Requires lean progressive context, explicit boundary instructions, and automated verification loops.
