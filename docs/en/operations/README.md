# Operations & Infrastructure (`docs/en/operations/`)

## What is this directory?
Contains operational runbooks, build and deployment instructions, observability guidelines, and recovery procedures.

## Purpose
Ensures production and staging operations are predictable, auditable, and resilient to failures.

## Inventory
- `deployment.md`: Build processes, release packaging, and continuous delivery procedures.
- `observability.md`: Structured logging, metrics, and diagnostics.
