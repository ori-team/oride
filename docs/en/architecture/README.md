# Systems Architecture (`docs/en/architecture/`)

## What is this directory?
Contains topology specifications, domain boundaries, modular composition rules, and formal Architecture Decision Records (ADRs).

## Purpose
Ensures the system maintains high cohesion and loose coupling throughout its evolution, preventing circular dependencies and structural degradation.

## Inventory
- `overview.md`: System topology, layers, and data flow diagrams.
- `clean-code-contract.md`: Strict software engineering and Clean Code contract.
- `adr/`: Formal Architecture Decision Records repository.
