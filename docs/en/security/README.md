# Security & Trust (`docs/en/security/`)

## What is this directory?
Contains trust models, threat vectors, security policies, and the strict security contract for the project.

## Purpose
Ensures security is an intrinsic design attribute, enforcing strict defenses against credential leaks, privilege escalation, and supply chain vulnerabilities.

## Inventory
- `threat-model.md`: Threat modeling utilizing the STRIDE methodology.
- `security-contract.md`: Mandatory code and execution security contract.
