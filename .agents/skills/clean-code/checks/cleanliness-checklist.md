# Clean Code Checklist
- [ ] Meaningful and intention-revealing names
- [ ] Functions are small and do one thing well
- [ ] Low coupling: no circular dependencies across modules
- [ ] High cohesion: related logic resides together
- [ ] No hidden side-effects in pure functions
- [ ] Explicit error types and error propagation
- [ ] No dead code or commented-out blocks
- [ ] All public APIs have concise documentation
